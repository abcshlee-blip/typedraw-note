# TypeDraw 노트

종이 노트 감성의 **타이핑 + 손그림** 노트 PWA. by 이성현.

- 주소: https://abcshlee-blip.github.io/typedraw-note/
- 설치: 삼성 인터넷/크롬에서 주소를 연 뒤 **홈 화면에 추가** → 독립 앱처럼 실행
- 저장: 모든 내용은 기기 안 IndexedDB에 자동 저장 (서버로 나가지 않음)

## 기능

### 표지와 책장
- 고무줄 밴드가 있는 종이 노트 표지, 여러 권 추가/이름 변경/삭제
- 표지 색 8종, 표지 무늬 5종(무지·천·줄·도트·크라프트)

### 1쪽 / 2쪽 펼침
- 화면 너비 540px 이상(폴드8 울트라 펼침, 태블릿) → 실제 노트처럼 **좌·우 2쪽 펼침**
- 좁은 세로 화면(폰 접은 상태) → 자동으로 **1쪽 보기**
- 하단 **자동 / 2쪽 / 1쪽** 버튼으로 언제든 직접 바꿀 수 있음 (선택은 기기에 저장)
- 쪽 추가, 이전/다음, 목차(썸네일) 서랍, 노트 안 검색

### 종이와 필기
- 속지 4종: 줄 노트 / 모눈 / 도트 / 무지
- 종이색 3종: 크림 / 화이트 / 다크
- **타이핑 모드**: 종이를 탭해 글상자를 만들고 입력, 드래그 이동, 크기 조절, 글꼴·크기·색 변경, 삭제
- **펜 / 형광펜 / 지우개**: 마우스·손가락·S펜(PointerEvent, 압력 감지) 지원, 굵기·색 선택, 실행 취소/다시 실행
- 삽입: 체크리스트, 오늘 날짜 스탬프, 사진(기기 이미지)
- 글꼴: 고딕(Noto Sans KR), 명조(Nanum Myeongjo), 손글씨(Nanum Pen Script), 개구(Gaegu), 고운(Gowun Dodum) — 오프라인 시 시스템 글꼴로 대체

### 저장과 내보내기
- IndexedDB 자동 저장 (그림·사진 포함), 새로고침·재실행 후에도 유지
- JSON 백업 내보내기/불러오기
- 현재 쪽 PNG 저장
- 인쇄 / PDF 내보내기 (`@media print` 최적화)

## 오프라인 / PWA
- `manifest.json`, `sw.js`(오프라인 캐시), 192/512 아이콘 포함
- 첫 방문 뒤에는 비행기 모드에서도 앱이 열립니다 (구글 폰트는 첫 로드 시 캐시)

## 개발 메모
- 빌드 도구 없음. `index.html` + `styles.css` + `app.js` 정적 파일.
- 쪽 좌표계는 800 × 1131 고정 → 화면 크기와 무관하게 필기·글자 위치가 유지됩니다.
- 아이콘: `python3 make_icons.py`
- 로컬 실행: `python3 -m http.server` 후 접속
