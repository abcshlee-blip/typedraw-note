# 노트 (TypeDraw 노트)

종이 노트 감성의 **타이핑 + 손그림** 노트 PWA. by 이성현.

- 주소: https://abcshlee-blip.github.io/typedraw-note/
- 설치: 삼성 인터넷/크롬에서 주소를 연 뒤 **홈 화면에 추가** → 독립 앱처럼 실행
- 저장: 모든 내용은 기기 안 IndexedDB에 자동 저장 (서버로 나가지 않음)

## 기능

### 표지와 책장
- 고무줄 밴드가 있는 종이 노트 표지, 여러 권 추가/이름 변경/삭제
- 표지 색 8종, 표지 무늬 5종(무지·천·줄·도트·크라프트)

### 1쪽 / 2쪽 펼침
- 화면 너비 540px 이상(폴드8 울트라 펼침, 태블릿) → 실제 노트처럼 **좌·우 2쪽 펼침**
- 좁은 세로 화면(폰 접은 상태) → 자동으로 **1쪽 보기**
- 하단 **자동 / 2쪽 / 1쪽** 버튼(넓은 화면은 **2쪽↔1쪽** 순환 버튼)으로 언제든 직접 바꿀 수 있음 (선택은 기기에 저장)
- 쪽 추가, 이전/다음, 목차(썸네일) 서랍, 노트 안 검색

### 넓은 필기 공간
- 상·하단 바의 여백을 줄여 종이가 두 바 사이 세로 공간을 꽉 채움 (화면 높이에 맞춰 자동 계산)
- **넓은 화면(540px 이상, 폴드 펼침·태블릿)은 하단 바를 딱 한 줄(48px)**로 압축 (v11)
  - 도구는 아이콘만, 색·굵기는 지금 색을 보여 주는 동그라미 버튼 하나로 묶고 누르면 바 위에 색·굵기 팝오버가 열림 (고르면 닫힘)
  - 보기 방식(자동/2쪽/1쪽)은 **2쪽 ↔ 1쪽** 순환 버튼 하나로 (지금 보기가 글자로 표시)
  - 접은 폰 화면(540px 미만)은 예전처럼 라벨·색 줄이 그대로 보이는 3줄 배치
- 바 높이가 바뀌거나(도구 옵션 줄 표시·글꼴 로딩) 화면이 돌아가도 종이 크기를 다시 맞춤
- 종이를 더 크게 보려면 오른쪽 위 **바 접기(⤢)** 로 상·하단 바를 숨기면 됨

### 전체 화면 몰입 보기 (바 접기)
- 상단 오른쪽 **바 접기(⤢)** 버튼 → 상·하단 바가 부드럽게 접혀 종이만 크게 보임
- 접힌 동안 오른쪽 위 작은 반투명 **바 펴기** 버튼(또는 Esc)으로 원래대로 복귀
- 접고 펼 때 종이 크기·글자 배치를 매 프레임 다시 계산해 어긋나지 않음

### 책장 넘김(페이지 플립)
- 쪽을 넘길 때 종이가 책등(가운데 접힘선)을 축으로 3D로 젖혀지며 넘어감 (약 0.46초, 접힘선 그늘·하이라이트)
- 2쪽 펼침: 다음 쪽은 오른쪽 장이 왼쪽으로 넘어가며 뒷장(새 왼쪽 쪽)이 드러나고, 이전 쪽은 왼쪽 장이 오른쪽으로 넘어감
- 1쪽 보기: 종이 바깥 끝을 축으로 책장처럼 젖혀짐
- 하단 `<` `>` 버튼·키보드 화살표·목차 이동에도 같은 효과, 넘기는 중에는 중복 입력을 막음

### 마우스 휠로 넘기기 (v12)
- 노트 화면에서 **휠을 아래(또는 오른쪽)로** 굴리면 다음 쪽, **위(또는 왼쪽)로** 굴리면 이전 쪽 (2쪽 펼침이면 1펼침씩, 3D 넘김 그대로)
- **한 번 굴리면 딱 한 쪽** — MX Anywhere 3S 같은 부드러운 휠은 한 번에 wheel 이벤트가 수십 개 오고 관성으로 계속 오므로,
  델타를 모아(36) 한 번만 넘기고 넘긴 뒤 0.62초 동안은 잠가 관성 꼬리로 두 번 넘어가지 않음(다시 넘기려면 손을 잠깐 멈추면 됨)
- 넘기지 않는 경우: 확대/축소(Ctrl·⌘+휠), 책장 화면, 목차·검색·설정·메뉴·색굵기 팝오버·이름 입력·확인창이 열려 있을 때,
  실제로 스크롤할 것이 있는 입력창 안, 첫 쪽에서 위로 / 마지막 쪽에서 아래로(조용히 무시)

### 손으로 넘기기(필기와 충돌 없이)
- **두 손가락 좌우 밀기** — 어떤 도구든
- **종이 바깥 좌우 여백**에서 안쪽으로 밀기 — 어떤 도구든
- **종이 바깥 모서리 32px 안쪽**에서 안쪽으로 밀기 (S펜 제외, 팬으로 쓸 때는 그대로 필기)
- **선택 도구**일 때 종이 위에서 좌우로 밀기
- 한 손가락·S펜으로 종이 안쪽에 그을 때는 절대 넘어가지 않음

### 뒤로가기(폰 버튼·스와이프)
- 뒤로가기를 눌러도 앱이 갑자기 닫히지 않음 — 단계별로 물러남
  1. 열려 있는 목차·검색·설정·메뉴·이름 입력·확인창 → 그것부터 닫힘
  2. 노트 편집 화면 → 책장으로 돌아감
  3. 책장 → **"노트 앱을 종료할까요?"** 확인 모달 (종이 톤 커스텀 모달)
- **계속 쓰기**(또는 바깥 탭·Esc) → 모달만 닫히고 다음 뒤로가기도 다시 막힘
- **종료** → 쌓아 둔 가짜 기록을 모두 물러나 실제로 앱 밖으로 나감 (PWA에서 앱 닫힘)
- 크로미움(삼성 인터넷·크롬)의 **History Manipulation Intervention** 대응 (v9·v10에서 보강):
  사용자 입력 없이 `pushState`로 쌓은 기록은 뒤로가기에서 건너뛰어져 앱이 바로 닫히므로,
  페이지를 열 때는 기록을 쌓지 않고, **User Activation이 실제로 붙는 제스처**
  (`pointerup`·`touchend`·`click`·`keydown`)에서 `navigator.userActivation.isActive`가 true일 때만
  한 번에 1칸씩(최대 3칸, `GUARD_DEPTH`) 채웁니다. `pointerdown`·`touchstart`는 모바일에서
  활성화가 아직 없어 쌓지 않습니다(펜으로 낙서한 뒤 뒤로가기에서 앱이 닫히던 원인).
  뒤로가기로 한 칸 빠지면 다음 제스처에서 다시 채웁니다.
- 그래서 **앱을 열고 아무것도 만지지 않은 채 곧바로 뒤로가기**를 누르면 앱이 닫힙니다(브라우저 정책상 막을 수 없음).
  화면을 한 번 터치하면 그다음부터는 위 1→2→3 순서로 물러납니다. 책장 하단의 `· v16`으로 지금 화면의 코드 버전을 확인할 수 있습니다.

### 종이와 필기
- 속지 4종: 줄 노트 / 모눈 / 도트 / 무지
- 종이색 3종: 크림 / 화이트 / 다크
- **타이핑 모드**: 종이를 탭해 글상자를 만들고 입력, 드래그 이동, 크기 조절, 글꼴·크기·색 변경, 삭제
- **글씨 색 8가지 (v13)**: 검정 · 진파랑 · **파랑** · 진빨강 · **빨강** · 초록 · 보라 · 주황 — 펜 색과 같은 톤에 또렷한 파랑·빨강을 더함 (다크 종이는 흰색 추가)
- **펜 / 형광펜 / 지우개**: 마우스·손가락·S펜(PointerEvent, 압력 감지) 지원, 굵기·색 선택, 실행 취소/다시 실행
- **펜 색 8가지 (v14)**: 검정 · 진파랑 · **파랑** · 진빨강 · **빨강** · 초록 · 보라 · 주황 — 타이핑 글씨 색과 같은 여덟 가지, 연필(펜) 도구에서도 또렷한 파랑·빨강을 바로 고를 수 있음 (다크 종이는 흰색 추가)
- 삽입: 체크리스트, 오늘 날짜 스탬프, 사진(기기 이미지)
- **사진 끌어서 옮기기 (v15)**: 사진을 넣으면 바로 선택되고, **어느 도구(펜·형광펜·지우개·타이핑·선택)에서든 마우스 왼쪽 버튼으로 사진을 눌러 끌면** 그대로 따라 옮겨짐. S펜·손가락으로 펜/형광펜을 쓸 때는 예전처럼 사진 위에 그대로 필기됨(마우스만 이동). 오른쪽 모서리 손잡이로 크기 조절, 위 손잡이 줄의 ⠿·×로 이동·삭제. 쪽 밖으로 끌어도 사진의 56px은 항상 종이 위에 남고, 놓으면 자동 저장
- **쪽을 건너서 사진 옮기기 (v16)**: 2쪽 펼침에서 마우스로 사진을 끌어 반대쪽 종이로 넘기면 **그 쪽 사진으로 실제로 옮겨 담김**(원래 쪽 객체 목록에서 빠지고 대상 쪽 기준 좌표로 저장). 끌고 있는 동안에는 종이 경계에 막혀 잘리지 않고 두 쪽 사이를 자유롭게 넘나들어 보이고, **사진 중심이 넘어간 쪽**이 새 주인이 됨. 쪽이 없는 빈 자리로는 넘어가지 않고, 놓으면 그 쪽 좌표로 자동 저장. 되돌리기(↶)는 사진이 있던 쪽과 넘어간 쪽을 **함께** 되돌림
- 글꼴: 고딕(Noto Sans KR), 명조(Nanum Myeongjo), 손글씨(Nanum Pen Script), 개구(Gaegu), 고운(Gowun Dodum) — 오프라인 시 시스템 글꼴로 대체

### 저장과 내보내기
- IndexedDB 자동 저장 (그림·사진 포함), 새로고침·재실행 후에도 유지
- JSON 백업 내보내기/불러오기
- 현재 쪽 PNG 저장
- 인쇄 / PDF 내보내기 (`@media print` 최적화)

## 오프라인 / PWA
- `manifest.json`, `sw.js`(오프라인 캐시), 192/512 아이콘 포함
- 첫 방문 뒤에는 비행기 모드에서도 앱이 열립니다 (구글 폰트는 첫 로드 시 캐시)

### 새 버전 받기 (v8~)
- `sw.js`의 `CACHE`(`typedraw-note-vN`), `CORE` 목록의 `?v=N`, `index.html`의 `?v=N`,
  `app.js`의 `APP_VERSION`, `version.txt` — 다섯 곳의 번호를 함께 올린다
  (책장 하단 `· vN`은 `app.js`가 `APP_VERSION`으로 채우므로 따로 고치지 않아도 된다)
- 설치 워커는 `skipWaiting()` + `clients.claim()`으로 바로 교체되고,
  앱은 `controllerchange`·`version.txt` 확인으로 새 버전을 스스로 적용한다
  (쓰는 중이면 방해하지 않고, 화면을 벗어날 때 적용)

## 개발 메모
- 빌드 도구 없음. `index.html` + `styles.css` + `app.js` 정적 파일.
- 쪽 좌표계는 800 × 1131 고정 → 화면 크기와 무관하게 필기·글자 위치가 유지됩니다.
- 아이콘: `python3 make_icons.py`
- 로컬 실행: `python3 -m http.server` 후 접속
